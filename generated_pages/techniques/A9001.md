# Assessment A9001: Impact Duration

**Summary**: Summary: This category contains assessments used to document the assessed duration of an impact.<br><br>Detail: This category contains assessments used to document how long an impact lasted, measured from the point at which an impact first manifested.<br><br>Duration is independent of how the activity was conducted. A single action can produce a permanent change and a campaign running for years can produce nothing which outlives it, so the persistence of the effect has to be assessed separately from the persistence of the effort.<br><br>For impacts assessed as harm, duration is the closest available proxy for severity. For impacts assessed as benefit, duration answers the campaign effectiveness question, because an actor who moves opinion for a fortnight has achieved something different from one who moves it for a decade.<br><br>A9001.001: Fleeting Impact and A9001.002: Lasting Impact are differentiated by whether the impact outlasted the activity which caused it. A9001.002: Lasting Impact and A9001.003: Permanent Impact are differentiated by whether the impact can be undone. An impact which has potential to return to its prior state, or has already done so after an extended period of time is lasting; one which cannot return to its prior state is permanent.
